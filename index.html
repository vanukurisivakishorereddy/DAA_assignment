About the Project

This is an interactive web-based project built to compare Linear Search and Binary Search side by side — both through their theoretical time complexity and through practical, measured execution performance. Instead of reading Big-O notation on a slide, you can watch the two algorithms work and see the numbers that back the theory.

Why This Project?

Every piece of software searches through data, and the algorithm behind that search decides whether an app feels instant or sluggish once the data grows. Seeing Linear Search and Binary Search run against the same input, and watching the gap between O(n) and O(log n) widen as N grows, builds the kind of intuition for algorithmic efficiency that's hard to get from a textbook alone.

Trace Logic Reference

Linear Search Trace Logic

In an array like [10, 20, 30, 40, 50] searching for target 40:

  1. Index 0: 10 ≠ 40 → Continue
  2. Index 1: 20 ≠ 40 → Continue
  3. Index 2: 30 ≠ 40 → Continue
  4. Index 3: 40 == 40 → Target Found!

Binary Search Trace Logic

In a sorted array [10, 20, 30, 40, 50, 60, 70] searching for target 60:

  1. Middle element = 40
  2. Target 60 > 40 → Discard left half
  3. Sub-array [50, 60, 70], Middle = 60
  4. Target 60 == 60 → Target Found in 2 steps!

About This Project

The reasoning, learning outcomes, and roadmap behind the analyzer.

About This Project

Search Algorithm Performance Analyzer is a data structures and algorithms project that compares Linear Search and Binary Search from two angles at once: the theoretical Big-O complexity you'd derive on paper, and a real, measured benchmark of the algorithms actually running in the browser. A dedicated visualizer then lets you step or play through each comparison the algorithm makes.

Why This Project?

Search is one of the most common operations in software, and the difference between O(n) and O(log n) is the difference between an app that stays fast as data grows and one that doesn't. Understanding search algorithm performance — not just memorizing the notation, but seeing it play out — is a foundational skill for writing efficient software and for technical interviews alike.

Learning Outcomes

Students working through this project will come away understanding:

  • ✓ Searching algorithms
  • ✓ Time complexity
  • ✓ Space complexity
  • ✓ Algorithm efficiency
  • ✓ O(n)
  • ✓ O(log n)
  • ✓ Practical vs theoretical performance
